Обо мне

Я QA инженер с опытом функционального тестирования в edtech-проектах. Заканчиваю обучение по курсу «Инженер по тестированию» (диплом: январь 2027). Имею высшее педагогическое образование. Внимательна, усидчива, стрессоустойчива, ответственна, умею работать с большим объёмом информации. 

Инструменты и технологии
- Ручное тестирование: функциональное, регрессионное, smoke, интеграционное.
- API-тестирование: (GET, POST, PUT, DELETE), JSON, REST.
- Тестовая документация: тест-кейсы, чек-листы, баг-репорты.
- SQL: простые запросы (SELECT, WHERE, JOIN, GROUP BY) для проверки данных.

Инструменты: TestIt, Yozhka, Miro, Git, GitHub, DevTools, Postman, SOAP (SoapUI).

Структура репозитория
- `test-cases/` — тест-кейсы (Smoke, позитивные, негативные).
- `checklists/` — чек-листы (функциональные, регрессионные).
- `bug-reports/` — баг-репорты (скриншоты и описания).
- `api-tests/` — коллекции Postman (JSON).
- `docs/` — документация (декомпозиция, тест-план).
